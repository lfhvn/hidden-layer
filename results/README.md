# Results

Committed experimental results. **Every number cited in a write-up, README,
or paper must trace back to a run directory in here.**

## Convention

```
results/<project>/<experiment-name>/<run-id>/
├── config.json      # Full ExperimentConfig (model, strategy, params, seed)
├── results.jsonl    # One JSON object per task run
└── summary.json     # Aggregates (accuracy, latency, cost, tokens)
```

- `<project>` matches the research area package, e.g. `multi-agent`,
  `selphi`, `introspection`, `steerability`.
- `<run-id>` is generated by the harness tracker:
  `{experiment_name}_{timestamp}_{confighash}`.
- Runs are produced with `harness.ExperimentTracker(base_dir="results/...")`.
  The default tracker directory `./experiments/` is gitignored scratch space;
  promote a run here only when it is final and citable.
- Never edit files in a run directory by hand. Rerun instead.

## Rules

1. **No claim without a results file.** If a document states a number, it
   links the run directory that produced it.
2. **Commit the config with the result.** A results.jsonl without its
   config.json is not reproducible and will be rejected in review.
3. **Record the git SHA.** Set `ExperimentConfig.git_hash` (e.g.
   `git rev-parse --short HEAD`) so the exact code state is recoverable.

## Running the Phase-0 smoke experiment

```bash
# Requires a local Ollama server (or pass --provider/--model for API)
python scripts/run_phase0.py --provider ollama --model llama3.2:latest
```

This runs `single` vs `debate` on the bundled 20-task arithmetic smoke set
(`shared/datasets/phase0_smoke.jsonl`) and writes runs under
`results/multi-agent/phase0-smoke/`. The task set is a deterministic
pipeline check, not a benchmark — it exists to prove the
run → track → commit loop end to end (ROADMAP Phase 0).
